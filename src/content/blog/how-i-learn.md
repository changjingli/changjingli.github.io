[六月总结](/posts/monthly-2026-06/)里提到过终身学习，当时篇幅有限，没展开说。回头看这十年，从 jQuery 到 Vue、React，再到如今的全栈和 Agent 开发，我几乎一直在学新东西。工具换了一轮又一轮，推动我学习的，往往是手头那个还不会解决的问题。

这些年我反复做的事大致相同：先弄清自己要解决什么，再把相关概念之间的关系理顺，找办法试一试，最后回头看哪里想错了。

今天我把这套方法论写下来，给同样要不断学新东西的人做个参考。

## 一、让问题决定学什么

初入行的时候我也有过知识焦虑，看见新课程、新概念就想收藏，生怕自己落后。后来发现，收藏得再多，也不能替我解决眼前的问题。现在我会先问：学了以后，要拿它做什么？

学英语，是为了看一手资料；学全栈，是为了把自己的产品想法做出来；最近研究 Agent，也是因为工作里遇到了相关问题。目标具体了，才知道自己需要的是大致了解，还是能独立做成一件事。

我会关注前沿账号，看看有什么新变化，但不会因为一个概念很热，就立刻找课从头学。具体工具的配置和平台规则，变化太快，遇到时再查；理解问题、表达想法、与人协作这些能力，换了工具仍然用得上，值得长期练。工作以外，我也会给文学、历史和逻辑留些时间，它们未必马上派上用场，却会慢慢改变我看问题的方式。

刚入行时，我用 jQuery 写页面，数据变了还要手动重新渲染。我一直想，能不能让页面随着数据自动变化？后来遇到 Vue，这个困扰终于有了更好的解法。那时我很快开始用它，不是因为它新，而是因为我已经被旧问题折腾过，知道它帮我省掉了什么。

## 二、理清概念，也看清上下游

进入陌生领域，我会先抓住几个核心概念，理清它们之间的关系，再看它的上下游。前者帮我理解它内部怎么回事，后者帮我知道它在实际工作中有什么用。

比如学本体，我先弄清类、实例和属性各自是什么意思，它们之间有什么区别和联系。接着再思考：这些知识由谁提供（生产者），整理之后又交给谁使用（消费者）？在我研究的 Agent 场景里，领域专家提供业务概念和规则，经建模整理后，供 Agent、LLM 或查询系统使用。

我的经验是“抓大放小”：先把知识框架搭起来，知道各部分是什么关系、在整个系统里起什么作用，不急着掌握所有细节。等到实际使用时，再带着具体问题补足。这样每次学到的新东西，都知道该放在哪里。

卡住时，我会先判断这个问题是否影响接下来要做的事：不影响，可以先记下来；如果关系到关键判断，就需要查清楚，或者找懂的人讨论，而不是带着错误的理解继续往下做。

## 三、用实践和输出校准理解

不过，有了这层理解，不代表已经学会了。“抓大放小”是知道哪些细节还没掌握，而不是以为自己已经全懂了。比完全不懂更麻烦的，是一知半解却以为自己懂了。完全不懂时，我还会查、会问；把半懂当成已懂，反而容易带着错误的理解继续往下做。妨碍学习的，往往不是未知，而是被我误当成已知的东西。

要识破这种一知半解，概念有了大致轮廓后，就得找事情试。读书、看成熟案例、向别人请教，或者让 AI 帮我解释，都是找办法的途径；但看懂一种方法，和在具体情境里用出来，是两回事。我以前写[《如何提高工时评估准确性》](/posts/project-time-estimation/)时就区分过知识和技能：菜谱里的“少许”“适量”可以看懂，真正掌握分寸还得自己下厨。

当然，动手也不是闭眼开干。遇到陌生领域，参考业内的优秀实践会事半功倍，先找一个做得好的例子，照着做起来，再回头补那些起初没看懂的地方。

我还会试着把学到的东西讲出来。比如学本体时，我让 AI 先解释，再问我五个问题。原以为自己懂了，回答时却把品牌当成了具体电脑；拿医疗场景试着建模，又把实体之间的关系写成了普通字段。AI 点出这些问题后，我才发现，几个词各自会解释，不代表它们之间的关系已经想清楚。

AI 的回答不能照单全收，尤其是业务规则和技术方案，还得找资料或拿实际场景核验，此时人的重心从找资料变为核验资料。AI 说我理解了不算数，还要看换一道题、换一个场景，我能不能独立处理。讲不清的地方回头补，做完再看哪些判断错了、哪些办法下次还能用。下一次碰到新问题，至少不用完全从头开始。

后来要做 React Native 时，我还没写过 React，但之前学 Vue 时，已经想过组件、数据和界面之间是什么关系。新的写法需要重新学，原先建立的理解却没丢。大学里学过的计算机基础也是这样：细节忘了不少，遇到新技术时，仍能帮我判断它大致在解决哪一类问题。

## 结语

对我来说，终身学习不是不停收藏新知识，也不是追着每个新工具跑。一个问题把我带进陌生领域，概念帮我看清它的结构，实践让我知道自己哪里没懂，复盘再把这次的经验带到下一次。读书和 AI 都能帮我找到办法，最后还是要自己用一次，才知道学到了多少。

## 附：我用的费曼学习提示词

下面是我学本体时用过的提示词。最后的讲解稿可以拿来对照，但不能代替我自己先回答、先尝试。

```text
请你作为我的学习教练，帮我用费曼学习法学习【填上你要学的主题】。请按以下步骤进行：

1. 先用简单、通俗的语言把这个主题解释一遍，当成是讲给一个完全没接触过的小白听。
2. 帮我拆解这个主题中的核心概念、关键原理和容易混淆的地方。
3. 向我提出 5 个检查理解的问题，让我用自己的话回答。
4. 根据我的回答，指出我哪里讲清楚了，哪里还存在理解漏洞。
5. 最后帮我生成一版「我可以讲给别人听」的简洁讲解稿，要求逻辑清晰、语言简单、有例子。
```
